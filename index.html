03每天从酒店出发，再回酒店

景点穿在吃饭中间，每天留休息时间

前三晚都住汉庭。第3天青岩是唯一一次稍远的往返，其余围绕贵阳老城；以下步行和车程均为估算。

DAY01

老城初见 · 文昌阁与甲秀楼

到贵阳，先吃一锅酸汤牛肉

汉庭 → 民生路 → 文昌阁 → 贵厨小十字店 → 甲秀楼 → 汉庭
  1. 12:00–15:00
    各自抵达龙洞堡机场

    这是选航班的目标到达时段，不是已确定航班。两人落地时间尽量差 1 小时内，在同一航站楼到达层公共区域会合；若差太久，先到的人去酒店寄存行李。

  2. 15:00–16:00
    机场 → 汉庭，入住后歇一会

    优先合乘网约车，目的地输入省府路4号这家汉庭。车程约 30–50 分钟；按 ¥40–70/车留预算。提前到、未到入住时间可先寄存。

  3. 16:00–17:30
    民生路小吃 → 文昌阁外观

    酒店到民生路步行约 3–8 分钟；小吃分着尝，再步行约 10–20 分钟去文昌阁周边拍照。只安排外观与街巷，不依赖室内开放。

  4. 17:30–19:00
    贵厨酸汤牛肉（小十字店）

    文昌阁 → 中山东路40号，步行约 10–15 分钟。点酸汤鲜牛肉双人份，预算约 ¥160；明确不吃鱼。

  5. 19:00–20:30
    甲秀楼河岸夜景 → 回汉庭

    餐厅到甲秀楼步行约 15–25 分钟，沿河看灯光、拍照。回酒店步行约 25–35 分钟，累了打车约 10–15 分钟。晚到就把夜景挪到第 2 晚。

吃喝约 ¥200 / 两人住宿：省府路4号汉庭

DAY02

黔灵山 · 午休 · 太平路与丝娃娃

上午逛山，中午吃牛肉自助

汉庭 → 俞记 → 黔灵山南门 → 土牛坊 → 汉庭午休 → 太平路 → 飞山街 → 汉庭
  1. 08:00–09:00
    俞记破酥包早餐 → 黔灵山南门

    酒店到俞记步行约 3–8 分钟。早餐后打车到“黔灵山公园南门”，约 15–25 分钟、¥15–25/车。

  2. 09:00–12:00
    黔灵山公园：南门进出的一小圈

    南门 → 山林步道 → 黔灵湖 → 南门，慢走约 2.5–3 小时。公园免费但须实名预约；不赶着走全园。猴子附近把食物收进包，不投喂。

  3. 12:15–13:30
    土牛坊全牛自助火锅（八角岩店）

    从公园南门打车到八鸽岩路79号，预留 10–20 分钟。预算两人 ¥120；出发前确认仍营业以及酸汤牛肉自助的实付价。若当天无法确认，就改去确认当天营业的贵厨小十字店吃酸汤牛肉套餐，餐费多留 ¥40–60。

  4. 14:00–16:30
    回汉庭，午休

    土牛坊 → 酒店打车约 15–25 分钟。给午休留足时间，换衣服、洗衣或喝咖啡都行。

  5. 17:00–20:30
    太平路 → 杨姨妈丝娃娃 → 回酒店

    汉庭到太平路步行约 10–15 分钟；逛完到飞山街171号步行约 15–25 分钟。吃丝娃娃、洋芋粑，饭后回汉庭步行约 20–30 分钟或短途打车。

吃喝约 ¥280 / 两人住宿：省府路4号汉庭

DAY03

一天往返古镇 · 仍住同一家酒店

青岩走石板巷，晚上吃干锅

汉庭 → 罗记早餐 → 青岩古镇 → 王万妈 → 汉庭午休 → 黔牛庄 → 汉庭
  1. 08:00–09:00
    金牌罗记肠旺面 → 出发

    酒店到蔡家街6号步行约 10–15 分钟。两碗面吃好后前往喷水池地铁站，或直接从早餐店叫车去古镇。

  2. 09:00–11:00
    喷水池 → 北京路 → 桐木岭 → 青岩北门

    1号线往窦官方向到北京路，换 3号线往桐木岭（省委党校）方向坐到终点，再网约车到青岩古镇北门，末段约 15–25 分钟。整个去程预留 1.5–2 小时；两人地铁＋末段车往返约 ¥80–100。嫌换乘麻烦，可全程打车约 60–90 分钟、单程按 ¥90–130 留预算，从备用金补差额。

  3. 11:00–14:30
    青岩古镇 → 王万妈卤猪脚 → 背街

    边逛边吃，午餐定位交通路44号。饭后走背街、石板巷，看定广门；门票先按两人通票 ¥120 留足，是否买通票看当天开放项目，主要逛街可选基础门票（参考 ¥10/人）。

  4. 14:30–17:30
    青岩 → 桐木岭 → 北京路 → 汉庭

    原路返回：3号线往洛湾方向到北京路，换 1号线往小孟工业园方向到喷水池，步行回酒店。早回一点，休息后再出门吃晚饭。

  5. 18:00–20:00
    黔牛庄干锅牛肉 → 回汉庭

    酒店打车到宝山北路九华路口，约 10–20 分钟。点干锅带皮牛肉，预算 ¥120–160/两人。这家不是已确认的牛肉自助；分店先电话核实，若有变动，可把干锅餐和第 1 天贵厨餐互换到确认有营业的时段。饭后打车返回酒店。

吃喝约 ¥300 / 两人住宿：省府路4号汉庭
